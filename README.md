# 鋸片診斷系統 (Saw Blade Diagnosis System)

這是一個專為鋸片專家設計的簡易診斷工具。客戶可以透過此網頁填寫機台與切削物資訊，並將資料編碼為分享連結傳回給專家評估。

## 功能特色

- **海軍藍專業 UI**：針對專業工具設計的視覺風格。
- **8 大診斷欄位**：包含轉速、規格、物料種類、厚度、性質、切割方式、困擾及品牌。
- **自動儲存**：填寫內容會自動儲存於瀏覽器，不怕遺失。
- **一鍵分享**：產生內含填寫資料的網址，方便透過 LINE 或 Email 分享。
- **LINE 導流**：整合「鋸片醫生」官方 LINE (@drhawer) 連結。

## 內容物

- `saw-blade-app.html` — 單一檔案版本。
- `index.html` — GitHub Pages 部署版本。

## 使用方式

1. 開啟網頁，填寫各項欄位。
2. 點擊「複製分享連結」，將網址傳給技術專員。
3. 或是點擊 LINE 按鈕直接聯繫專家。
